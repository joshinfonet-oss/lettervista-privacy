# LetterVista Privacy Policy — GitHub Pages

This folder is the minimal site to publish the LetterVista privacy policy using GitHub Pages.

Before making the repository public, edit `index.html` and replace every highlighted placeholder (publisher's legal name, privacy/support email, effective/update dates, children’s privacy statement, and postal address if applicable). Also ensure the account deletion route described in the policy is actually operational.

## Publish
1. Create a **public** GitHub repository named `lettervista-privacy`.
2. Upload `index.html` from this folder to the repository root and commit it.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/(root)`, then **Save**.
5. Wait for the Pages deployment to finish. The site URL will be `https://YOUR-GITHUB-USERNAME.github.io/lettervista-privacy/`.
6. Open that URL in a private/incognito browser window and verify it loads before using it in Play Console.

GitHub Pages sites are public. Do not commit secrets, app keys, credentials, or private user data to this repository.
